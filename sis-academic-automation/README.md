# SIS Academic Automation

A controlled institutional pilot developed as an internship project for SKILLITx.

## Overview

This project automates major academic administration processes through n8n, Supabase and PostgreSQL.

## Completed Workflows

- Student intake and profile management
- Course and subject enrollment
- Marks intake and validation
- Results approval and publication
- Transcript generation and delivery
- Administrative search and dashboard reporting
- Notification dispatching
- Scheduled operations and monitoring

## Deferred Workflows

- Workflow 06 — HEC Enrollment Reporting
- Workflow 10 — Global Error Handler

## Technology Stack

- n8n 2.4.0
- Supabase
- PostgreSQL
- JavaScript
- PowerShell
- HTML and CSS

## Project Status

The system is complete as a controlled institutional pilot. It is not currently presented as a hosted production Student Information System.
