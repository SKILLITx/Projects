# HEC Enrollment Report Google Sheets Template

The provisioner creates `SIS — HEC Enrollment Report Template` with:

- `HEC_Enrollment_Report`
- `Report_Metadata`
- `Validation_Lists`
- `Instructions`

The report sheet contains institution, campus, program, term, student, enrollment, credit, CGPA, standing and report-run fields. It is a demonstration structure and must be mapped to the institution's current official HEC submission format before a real submission.
