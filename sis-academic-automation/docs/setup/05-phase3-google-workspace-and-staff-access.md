# Phase 3 — Google Workspace and Staff Access

## Deliverables

- six Google Form specifications;
- linked response-sheet and normalized queue contracts;
- Drive folder plan;
- one-run Apps Script Google Workspace provisioner;
- Google Docs transcript template;
- HEC Google Sheets template;
- operational dashboard template;
- Supabase Auth staff portal;
- local configuration scripts;
- first-staff bootstrap procedure;
- authorization test guide and matrix;
- automated Phase 3 package validator.

## Verification groups

### Group A — Google Workspace

1. Run the provisioner.
2. Run `verifyPhase3Assets`.
3. Confirm one JSON result.

### Group B — Staff access

1. Create one Supabase Auth staff user.
2. Run the local bootstrap SQL generator.
3. Configure the portal locally.
4. Sign in and run the authorization verification transaction.

Phase 4 workflow JSON is not generated until both groups pass.
